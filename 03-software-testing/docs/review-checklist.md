# Reviewer checklist

- [ ] The question is self-contained and states every convention it depends on
- [ ] Exactly one correct answer; precision and units are specified
- [ ] The answer is recomputed by code or traced to a cited section (title and locator)
- [ ] The cited source was opened and the quoted text matches
- [ ] The designed shortcut produces a different answer and is plausible
- [ ] No hedge words; no trick wording; no dependence on the date the question is asked
- [ ] The rationale lets another expert reproduce the answer by hand
- [ ] Item tested against at least one model with several attempts; pass rate recorded
- [ ] Item is not answerable by a single web search
