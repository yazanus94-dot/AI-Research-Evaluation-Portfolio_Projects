## A01 - HRV time-domain: RMSSD

**Question:** An ECG analysis yields these 8 consecutive NN (normal-to-normal) intervals in milliseconds: 800, 810, 790, 830, 760, 800, 845, 790. Compute RMSSD, the square root of the mean of the squared differences between successive NN intervals. Give the value in ms, rounded to 2 decimal places.

**Answer:** `44.16`

**Reasoning:** Successive differences are 10, -20, 40, -70, 40, 45, -55 (7 values). Squares sum to 13650; the mean over the 7 differences is 1950; the square root is 44.16 ms.

**Designed shortcut:** Dividing the sum of squares by the number of intervals (8) instead of the number of successive differences (7). (gives `41.31`)

**Verification:** code (`verifiers.rmssd`)

## A02 - HRV time-domain: SDNN

**Question:** An ECG analysis yields these 8 consecutive NN (normal-to-normal) intervals in milliseconds: 800, 810, 790, 830, 760, 800, 845, 790. Compute SDNN as the sample standard deviation (Bessel-corrected, divisor n-1) of the intervals. Give the value in ms, rounded to 2 decimal places.

**Answer:** `26.04`

**Reasoning:** Mean = 803.125 ms. Sum of squared deviations = 4746.875; divided by n-1 = 7 gives 678.125; square root = 26.04 ms.

**Designed shortcut:** Using the population standard deviation (divisor n), which many libraries apply by default. (gives `24.36`)

**Verification:** code (`verifiers.sdnn`)

## A03 - HRV: pNN50 convention

**Reasoning:** The differences with absolute value above 50 ms are 70 and 55, so NN50 = 2. Dividing by the 8 NN intervals gives 25.0%.

## A04 - Heart rate: averaging pitfall

**Question:** Two successive RR intervals measured on an ECG are 600 ms and 1200 ms. Let (a) be the average of the two instantaneous heart rates (60000/RR for each interval) and (b) be the heart rate computed from the mean RR interval (60000/mean RR). Compute (a) minus (b) in beats per minute, rounded to 2 decimal places.

**Answer:** `8.33`

**Reasoning:** (a) = (100 + 50)/2 = 75 bpm. (b) = 60000/900 = 66.67 bpm. The difference is 8.33 bpm because 1/x is convex: averaging rates is not the same as the rate of the average interval.

**Designed shortcut:** Assuming both methods give the same heart rate. (gives `0.0`)

**Verification:** code (`verifiers.jensen_gap_bpm`)

## A05 - Sampling: aliasing

**Question:** A 60 Hz mains-interference component is present in an analogue ECG that is digitised at 90 Hz with no anti-aliasing filter. At what frequency, in Hz, does the component appear in the one-sided spectrum of the sampled data (0 to fs/2)? Give an integer.

**Answer:** `30`

**Reasoning:** Nyquist frequency is 45 Hz, so 60 Hz aliases. The alias is |60 - 1x90| = 30 Hz, which lies inside the 0-45 Hz band.

**Designed shortcut:** Assuming the component stays at 60 Hz because it is 'above' the band of interest. (gives `60`)

**Verification:** code (`verifiers.alias_frequency`)

## A06 - Filtering: zero-phase band-pass

**Question:** A digital Butterworth band-pass filter is designed with scipy.signal.butter(4, [5, 15], btype='bandpass', fs=100); its -3 dB points are exactly 5 Hz and 15 Hz and its passband gain is 1. The filter is applied with zero-phase forward-backward filtering (scipy.signal.sosfiltfilt). By how many dB, to the nearest 0.1 dB, is a steady 5 Hz sinusoid attenuated in the output relative to a unit passband gain?

**Answer:** `6.0`

**Reasoning:** One pass has |H| = 1/sqrt(2) at the -3 dB edge. Forward-backward filtering applies the filter twice in effect, so the magnitude response is |H|^2 = 0.5, i.e. -6.02 dB.

**Designed shortcut:** Quoting the single-pass -3 dB design value and forgetting that filtfilt squares the magnitude response. (gives `3.0`)

**Verification:** code (`verifiers.filtfilt_attenuation_db`)

## A07 - Spectral analysis: frequency resolution

**Question:** An RR-interval tachogram is resampled to 4 Hz and analysed with Welch's method using nperseg = 256 (no zero padding). The one-sided frequency bins are k * fs/nperseg for k = 0..128. How many of these bins lie in the closed interval 0.04 Hz to 0.15 Hz (the conventional low-frequency HRV band)? Give an integer.

**Answer:** `7`

**Reasoning:** Bin spacing is 4/256 = 0.015625 Hz. Bins k = 3 (0.0469 Hz) to k = 9 (0.1406 Hz) fall inside 0.04-0.15 Hz; k = 2 is 0.03125 Hz and k = 10 is 0.15625 Hz. That is 7 bins.

**Designed shortcut:** Rounding the band edges to the nearest bin instead of counting only bins that actually fall inside the band. (gives `8`)

**Verification:** code (`verifiers.welch_lf_bins`)

## A08 - Timing resolution of R-peak detection

**Question:** R peaks are located by taking the sample index of the local maximum in a signal sampled at 250 Hz, with no interpolation. Assume true peak times are arbitrary (continuous) so that each detected time is rounded to the nearest sample. What is the largest possible absolute error, in ms and to the nearest 0.1 ms, of a single RR interval computed as the difference of two detected peak times?

**Answer:** `4.0`

**Reasoning:** Each peak time is wrong by at most half a sample (2 ms at 250 Hz), in either direction. An RR interval subtracts two such times, so the errors can add: 2 + 2 = 4 ms, i.e. one full sample period.

**Designed shortcut:** Reporting the per-peak half-sample error (2 ms) as the interval error. (gives `2.0`)

**Verification:** code (`verifiers.rr_quantisation_max_ms`)

## A09 - Poincare plot: SD1

**Question:** An ECG analysis yields these 8 consecutive NN (normal-to-normal) intervals in milliseconds: 800, 810, 790, 830, 760, 800, 845, 790. For the Poincare plot of (RR_n, RR_n+1), define SD1 = sqrt(0.5 * Var(dRR)), where dRR are the successive differences and Var is the sample variance with divisor (number of differences - 1). Give SD1 in ms, rounded to 2 decimal places.

**Answer:** `33.71`

**Reasoning:** The 7 differences are 10, -20, 40, -70, 40, 45, -55 with mean -1.43. Their sample variance is 2272.62; half of that is 1136.31; the square root is 33.71 ms.

**Designed shortcut:** Using RMSSD/sqrt(2). That equals SD1 only when the mean difference is zero and the same denominator is used; here it gives 31.22. (gives `31.22`)

**Verification:** code (`verifiers.sd1`)

## A10 - QRS detector design: window scaling

**Question:** In the original Pan-Tompkins QRS detector paper, the moving-window integrator is 30 samples wide at the paper's sampling rate of 200 samples/s (150 ms). To keep the same 150 ms window duration when the same detector is run on a 360 Hz recording, how many samples wide must the window be? Give an integer.

**Answer:** `54`

**Reasoning:** The window is defined by duration, not sample count: 150 ms at 200 Hz is 30 samples, so at 360 Hz it is 0.150 s * 360 = 54 samples.

**Designed shortcut:** Keeping the 30-sample window, which shortens it to about 83 ms and changes the integrator's behaviour. (gives `30`)

**Verification:** both (`verifiers.window_samples`)
